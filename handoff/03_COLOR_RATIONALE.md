# เหตุผลเรื่องสี (เขียวเสจ + น้ำตาลเอิร์ธโทน + ครีม)

## ทำไมเหมาะกับแอปนี้ (ความเห็นทีม)
- แอปเกี่ยวกับใจและสัตว์เลี้ยง → ต้องรู้สึก **สงบ อบอุ่น เป็นส่วนตัว** ไม่ใช่โรงพยาบาล (ฟ้า-ขาว) และไม่ใช่แอปฟิตเนส (นีออน)
- เขียวเสจ = ธรรมชาติ ต้นไม้ สมุนไพร / น้ำตาล = ขนสัตว์ ไม้ ดิน / ครีม = กระดาษสมุดบันทึก
- **ไม่ใช้สีแดงหรือส้มสด** กับเรื่องใจหรือภาระ เพราะจะอ่านเป็น "อันตราย/ผิดปกติ" ซึ่งขัดกับกฎห้ามตีตรา

## ข้อควรระวัง
- คนตาบอดสีแดง-เขียว อาจแยก sage กับ bark ได้ยาก → กราฟต้องมี **ป้ายข้อความ + ตัวเลข n** ใต้แท่งเสมอ อย่าใช้สีอย่างเดียวสื่อความหมาย
- ห้ามใช้ honey เป็นสีตัวอักษรบนครีม (contrast ต่ำ) — ใช้เป็นพื้นหลังของ badge เท่านั้น
- ถ้าเปลี่ยนสีใดๆ ให้ปรับ "ความสว่าง" ไม่ใช่ "เฉดสี" แล้วตรวจ contrast ซ้ำ (เช่นที่ webaim.org/resources/contrastchecker)
- ห้ามไล่สี (gradient) บนตัวอักษร — ทีมไม่ชอบและอ่านยาก
