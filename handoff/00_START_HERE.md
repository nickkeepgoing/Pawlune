# เริ่มที่นี่ — สำหรับเพื่อนที่รับงานต่อ (Paw Diary)

โปรเจกต์: เว็บแอป "Paw Diary" สำหรับแข่ง ToBeIT'70 (ธีม Healthy Living) ที่คณะเทคโนโลยีสารสนเทศ
สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง วันแข่งออนไซต์ 28–29 พ.ย. 2569

## อ่านตามลำดับนี้
1. `../README.md` — ภาพรวม kit + TODO 5 ข้อที่ต้องทำก่อนเขียนโค้ด
2. `01_WORK_PLAN.md` — แผนงานรายวัน ใครทำอะไร จุดตรวจ
3. `04_SETUP_GUIDE.md` — สมัครทุกเว็บ + เอา key มาใส่ ทีละขั้น (ทำอันนี้ก่อนเปิด Claude Code)
4. `02_FEATURE_EXPANSION.md` — ฟีเจอร์ที่คิดเพิ่ม + คะแนนความเป็นไปได้/ความน่าใช้ + วิธีทดสอบกับผู้ใช้
5. `03_COLOR_RATIONALE.md` — ทำไมเลือกสีนี้ + ผลตรวจ contrast
6. `05_PROMPT_FOR_CLAUDE.md` — prompt สำเร็จรูป ก๊อปไปวางใน Claude ของคุณเพื่อให้ช่วยขยายแผนต่อ

## กฎ 3 ข้อที่ห้ามพลาด
- ห้ามอัป `.env.local` หรือ key ใดๆ ขึ้น GitHub / แชท / LINE กลุ่ม ถ้าหลุดให้ไปกด rotate key ใหม่ทันที
- ตัวเลขทุกตัวในแอปมาจาก engine (`tools/reference_engine.py` เป็นต้นฉบับ) ห้ามให้ AI คิดเลขหรือแต่งตัวเลข
- ห้ามใช้คำว่า "บำบัด / รักษา / ทำให้ใจดีขึ้น / ซึมเศร้า" ในแอปและสไลด์ (เหตุผลอยู่ใน `../docs/EVIDENCE.md`)
