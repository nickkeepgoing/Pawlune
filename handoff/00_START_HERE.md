# เริ่มที่นี่ — สำหรับเพื่อนที่รับงานต่อ (Pawlune)

โปรเจกต์: เว็บแอป "Pawlune" สำหรับแข่ง ToBeIT'70 (ธีม Healthy Living) ที่คณะเทคโนโลยีสารสนเทศ
สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง วันแข่งออนไซต์ 28–29 พ.ย. 2569

## อ่านตามลำดับนี้
1. `../README.md` — ภาพรวม kit + TODO 5 ข้อที่ต้องทำก่อนเขียนโค้ด
2. `01_WORK_PLAN.md` — แผนงานรายวัน ใครทำอะไร จุดตรวจ
3. `04_SETUP_GUIDE.md` — สมัครทุกเว็บ + เอา key มาใส่ ทีละขั้น (ทำอันนี้ก่อนเปิด Claude Code)
4. `02_FEATURE_EXPANSION.md` — ฟีเจอร์ที่คิดเพิ่ม + คะแนนความเป็นไปได้/ความน่าใช้ + วิธีทดสอบกับผู้ใช้
5. `03_COLOR_RATIONALE.md` — ทำไมเลือกสีนี้ + ผลตรวจ contrast
6. `05_PROMPT_FOR_CLAUDE.md` — prompt สำเร็จรูป (รันแล้ว ผลอยู่ในข้อ 7)
7. `06_REVIEW.md` — ผลรีวิวแผน: ฟีเจอร์ ลำดับงาน จุดที่ผู้ใช้จะงง สี คำตอบเรื่อง Daylio
8. `07_TEST_SHEET.md` — แบบทดสอบกับเจ้าของสัตว์ 5 คน พิมพ์ไปใช้ได้เลย
9. `08_CODE_STATUS.md` — **โค้ดแอปเขียนครบแล้ว** วิธีรัน + สิ่งที่ต้องเช็ค
