# สถานะโค้ด (26 พ.ย. 2569 ค่ำ)

**ฟีเจอร์หลัก: ทดลองรับเลี้ยงเพื่อนจากศูนย์ 14 วัน** — จับคู่ → ขอทดลอง → ศูนย์อนุมัติ → WHO-5 + ST-5 วันแรก → เช็คอินทุกวัน → วันที่ 14 ดูผลก่อน-หลังแล้วตัดสินใจ → รับเลี้ยง (ส่งความรู้สึกทุก 30 วัน) หรือคืน (ศูนย์หาบ้านใหม่ให้น้อง ผู้ใช้หาเพื่อนใหม่ได้)

ทดสอบแล้ว: engine ทั้งหมด (`npm run test:engine` ต้อง PASS 7 บรรทัด) · ตรวจ type แบบคร่าว · **ยังไม่ได้ `npm run build` หลังรอบนี้**

## ติดตั้งครั้งแรก
```
npm install
copy .env.example .env.local     (Windows) แล้วใส่ key
npm run test:engine
npm run build
```
Supabase SQL Editor รันตามลำดับ: `0001_init.sql` → `0003_username_avatar.sql` → `0004_trial.sql` → `0005_cat_first.sql` → `0006_grants.sql`
(0005: ฟิลด์แมว ข้อตกลงก่อนทดลอง ผูกเจ้าหน้าที่กับศูนย์ ถ้ามีบัญชีศูนย์อยู่แล้ว ให้รัน `npm run seed:demo` ใหม่ หรือตั้ง `profiles.shelter_id` เอง)
(ถ้าเคยรัน `0002_photos.sql` ไปแล้วไม่เป็นไร 0004 จะลบตารางนั้นให้)

## บัญชีเดโม
```
npm run seed:demo
```
- `demo` — ผู้ใช้ มีบันทึก 60 วัน และกำลังทดลองเลี้ยง "ถั่วแดง" วันนี้ = วันที่ 14 (โชว์การตัดสินใจสด)
- `shelter` — เจ้าหน้าที่ศูนย์ (รหัสผ่านเดียวกัน) เข้า ตั้งค่า → หน้าศูนย์
- รันใหม่เช้าวันเดโมทุกครั้ง

## หน้าที่มี
| หน้า | ทำอะไร |
|---|---|
| `/adopt` | กรอกสิ่งที่มองหา (ชนิด แพ้ ขนาด อายุ พลังงาน นิสัย ที่อยู่ รั้ว ชม.ไม่อยู่บ้าน งบ ครอบครัว ประสบการณ์) → รายชื่อที่เข้ากัน พร้อม ✓ เหตุผล / ! ข้อควรระวัง |
| `/adopt/[id]` | รายละเอียดน้อง + วิธีทดลอง 14 วัน + ยินยอมแชร์ข้อมูลกับศูนย์ → ส่งคำขอ |
| `/trial` | สถานะ, วันที่ X/14, แบบวัดวันแรก, วันที่ 14: ตาราง WHO-5/ST-5/อารมณ์ ก่อน-หลัง + ฟอร์มตัดสินใจ, รายเดือน |
| `/shelter` | เจ้าหน้าที่: อนุมัติ/ไม่อนุมัติ, เห็นความพร้อม+ความรู้สึกที่ผู้ใช้ส่ง, ยืนยันรับคืน |
| `/wellbeing/st5` | แบบประเมินความเครียด ST-5 กรมสุขภาพจิต |
| `/learn/care` | คู่มือ 14 วันแรก + ตารางค่าใช้จ่ายจริงพร้อมแหล่ง + เครื่องคิดงบ + ติดต่อศูนย์ กทม. |
| `/learn/therapy` | สัตว์บำบัดแบบกระชับ + ถ้าอยากให้หมาเป็นสุนัขนักบำบัด |
| `/report` | รายงานเป็นรูปภาพ (เพิ่ม ST-5 และการทดลองเลี้ยง) |

เอาออกแล้ว: อัลบั้มรูป, สรุปด้วย AI, PDF
